# Google Sheets Scripts

Централизованная коллекция скриптов автоматизации и надстроек на базе **Google Apps Script** для рабочих таблиц Google Sheets.

---

## Проекты и модули

| Модуль | Назначение |
| :--- | :--- |
| [`order-sorting`](order-sorting/) | Двухуровневая сортировка заказов: срочные (зеленые) наверх, группировка по объему, сохранение выпадающих списков и форматирования. |

---

## Стандарты разработки
- Скрипты ориентированы на чистый JavaScript (V8 Engine) платформы Google Apps Script.
- Пакетные операции чтения/записи для максимальной скорости (`getValues`/`setValues`).
- Подробные инструкции по установке и преодолению политик авторизации Google.
