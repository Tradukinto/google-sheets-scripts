# Auto Jump to Bottom (Google Apps Script)

Скрипт для Google Таблиц, который при каждом открытии книги автоматически переводит курсор на первую пустую строку в самом низу столбца **A** на трех последних листах.

---

## 1. Назначение и логика работы

В рабочих таблицах учета переводов в столбцах **K–N** протянуты формулы с нулевыми значениями, поэтому стандартный `getLastRow()` перебрасывает курсор в самый низ листа. Данный скрипт решает эту проблему:

- Обрабатывает **3 последних листа** книги (`sheets.slice(-3)`), независимо от их названий (например, `11.26`, `11_Вова`, `11_Света` или листы следующего месяца).
- В каждом из этих листов ищет последнюю непустую ячейку именно в столбце **A** («Номер заказа»).
- Выделяет и прокручивает экран к первой пустой ячейке (`lastRow + 1`, столбец `1`).
- Возвращает фокус на тот лист, который был открыт пользователем (если он входит в число последних трех).

---

## 2. Техническое задание (ТЗ) для восстановления с нуля

1. **Среда выполнения:** Google Apps Script (контейнерный скрипт, привязанный к таблице через **Расширения → Apps Script**).
2. **Триггер:** простой триггер `onOpen()` (срабатывает автоматически при открытии или обновлении вкладки с таблицей, дополнительная настройка триггеров не требуется).
3. **Алгоритм:**
   - Получить активную книгу: `SpreadsheetApp.getActiveSpreadsheet()`.
   - Получить список всех листов: `ss.getSheets()`.
   - Выбрать 3 последних листа: `sheets.slice(-3)`.
   - Запомнить текущий активный лист: `ss.getActiveSheet()`.
   - Для каждого листа из выборки:
     - Считать значения столбца `A:A` через `getRange("A:A").getValues()`.
     - Пройти массив с конца до первой непустой строки (`values[i][0] !== ""`) и зафиксировать `lastRow = i + 1`.
     - Активировать ячейку `sheet.getRange(lastRow + 1, 1).activate()`.
   - Если исходный активный лист входит в `targetSheets`, вернуть на него фокус через `currentActive.activate()`.
