# Auto Buffer Rows (Автодобавление пустых строк)

Скрипт для **Google Apps Script**, автоматически поддерживающий буфер из 10 пустых строк между последним заказом и блоком итогов («Исходная выручка...»).

---

## Возможности
- **Автоматический триггер `onEdit`**: срабатывает при заполнении новых строк без необходимости нажимать кнопки.
- **Динамический поиск подвала**: находит блок «Исходная выручка» и вставляет строки строго перед ним, сдвигая итоги вниз.
- **Копирование форматирования и формул**: автоматически переносит выпадающие списки, цвета и расчетные формулы (колонка «Сумма») на новые строки.
- **Очистка идентификатора**: очищает колонку A («Номер заказа») в новых строках, гарантируя корректный расчет буфера.

---

## Установка в Google Таблицу

1. Откройте таблицу в Google Sheets.
2. Перейдите в меню: **Расширения** → **Apps Script**.
3. В панели слева нажмите **`+`** (Добавить файл) → **Скрипт**.
4. Назовите файл `AutoBufferRows` и вставьте содержимое файла [`auto-buffer-rows.js`](auto-buffer-rows.js).
5. Сохраните проект (`Ctrl + S`).
